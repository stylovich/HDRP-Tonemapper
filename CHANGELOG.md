# Changelog

## [0.1.0] - 2026-11-08

### Added

- FidelityFX LPM Tonemapping: a port of AMD FidelityFX LPM 1.20200225 as an HDRP custom post process. Defaults are 64 / 6 / 0.3 with neutral crosstalk {1, 1, 1/32}. Includes an optional Highlight Desaturation extension.
- AgX Tonemapping: AgX in the Rec.2020 form used by Blender 4.x, with the Punchy, Golden, and Custom (ASC CDL) looks.
- Custom inspectors with tone curve previews, a registration check, and a check for HDRP's Tonemapping.
- "Tonemapping Profiles" sample.
